Для запуска задачи необходимо установить Flask:

```bash
pip install flask
```

## Writeup

1. **Первоначальный анализ**  
   После попадания на сайт, если пролистать ниже, можно увидеть фейк-флаг. Однако он нам не интересен.

2. **Первое действие веб-разработчика**  
   Как поступают настоящие вебберы? Правильно! Сразу проверяют `robots.txt`.  
   Мы видим, что на сайте упоминается какой-то URL для входа: `/hibro/login/`.

3. **Попытки взлома**  
   - Брутфорсинг логинов или поиск SQL-инъекций не дает результата.
   - После долгих попыток переходим на базовый URL `/` и нажимаем `CTRL+U`.

4. **Подсказка в комментариях**  
   В исходном коде страницы мы находим комментарий:

   ```html
   <!-- Maybe style.css? -->
   ```

   Следуем подсказке и открываем файл стилей, где обнаруживаем следующую информацию:

   ```css
   /* У админа альцгеймер, так что я оставил тут его логин что бы впредь он его не забывал MarcusovGHGSCCFV123@gmail.com */
   ```

   Теперь у нас есть логин администратора.

5. **Поиск пароля**  
   - Перебор паролей на URL или в исходных файлах результата не дает.  
   - Единственное решение — брутфорс пароля. Используем пароль из базового набора Burp Suite Intruder: `elaine`.

6. **Обход ошибки 403**  
   После входа на сайт возникает ошибка 403 и сообщение внизу: `maybe bypass?`.  
   Понятно, что нужно обойти ошибку. Для этого:
   - Перехватываем POST-запрос при логине.
   - Добавляем заголовок: `X-real-ip: 127.0.0.1`.

7. **SSTI-уязвимость**  
   На сайте присутствует обычная SSTI. Используем полезную нагрузку для чтения файлов и получаем флаг.
